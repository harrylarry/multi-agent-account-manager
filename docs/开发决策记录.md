# 开发决策记录

## 2026-11-26 移除协作房间

用户明确取消协作房间，包括入口、模板、自动派发和本机数据。新版升级清理 App 沙盒内的旧记录、附件、恢复日志和对应发送记录。既往 v4 房间需求及验收只作为历史。当前优先保障 Muse/Hark 多账号切换、登录隔离、代理和额度同步。

## 2026-11-26 房间与任务解耦

用户确认房间以成员和指挥为长期配置，同一个房间可先后承接不同任务。新增时无需目标、预设类别或逐个绑定执行角色。用户发送消息后，指挥默认判断直接回答或自动分派，不增加每轮人工派发确认。App 通过各成员的隔离会话传递共享记录。每次任务的分工由指挥提出，客户端校验成员范围、独立审核和轮次门禁，定稿继续由用户确认。既有模板任务及档案继续可访问。
