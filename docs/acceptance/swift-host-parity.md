# 原版叠号迁移验收

基准是原 Tauri 日常版 0.1.26，提交 0bd4341537516826ee957cf50bf69710e03572bc。新分支从这个提交开始。保留两套构建入口，逐项核对原包与 Swift 包。

## 本轮范围

Swift 管理应用生命周期、管理页 WebView、本地资源和消息桥。界面沿用同一份原版 HTML、TypeScript、CSS 及图标，UIKit Liquid Glass 控件由原 Swift 文件同时供两个宿主编译。账号列表用原 Rust 的 provider 定义、账号文件解析和 UUID 冲突检测，只读提供屏幕所需的快照。Tauri 构建继续走原有消息通道。

本轮是宿主与管理页的预览。完整会话和原版后端服务接线仍在迁移。预览使用独立安装标识。它读取自己容器里的原格式文件，因此留待使用原签名身份的覆盖升级验证账号续用。

## 开发验证

运行原版前端构建和已有测试，再运行 Swift 资源构建。在装有 Xcode 26 和 XcodeGen 的 Mac 上，用 [Swift 宿主 CI](../../.github/workflows/swift-host.yml) 内相同命令生成工程、构建 Rust 静态库并运行模拟器。

真机通过之前保持分支为草稿。后续优先迁移原 AccountWebViewController 所走的会话协调和桥接，再逐项迁入服务调用；每个入口用原版同一场景核对结果与失败回执。
